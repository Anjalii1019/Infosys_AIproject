# AI Enabled Recommendation Engine

## Milestone 1 – Data Preparation

This project builds a user–item interaction matrix for an e-commerce
recommendation system using the Olist dataset.

### Steps Performed
- Loaded and merged orders, order items, and reviews datasets
- Used review scores as explicit user feedback
- Constructed a user–item interaction matrix
- Applied sampling to handle large-scale data

### Technologies Used
- Python
- Pandas
